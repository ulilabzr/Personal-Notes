# Personal Notes

A simple notes web app built with React and Vite.  
You can create, edit, and delete notes instantly in a clean and fast interface.  
Perfect for anyone who wants a lightweight personal note manager without extra clutter.

## 🧩 What You Can Do

- Create new notes in seconds.  
- Edit or delete existing notes easily.  
- View all notes in a minimal, distraction-free layout.  
- Enjoy instant UI updates thanks to React’s reactivity.  
- Store data locally so your notes stay available even after refresh.

## 💡 Why It’s Useful

- Works fast in any modern browser.  
- Helps you jot down ideas, reminders, or to-do lists quickly.  
- Great for students, developers, or anyone who wants simplicity.

## 🧭 How It Works

1. The app runs in your browser using React and Vite.  
2. Notes are stored in the browser’s local storage.  
3. Each action (add, edit, delete) updates the data instantly.  
4. You can close and reopen the tab without losing your notes.
